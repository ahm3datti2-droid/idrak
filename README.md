# IDRAK | إدراك — Digital Awareness & Algorithm Intelligence Platform

**وعي. فهم. تحكم.** — افهم العالم الرقمي قبل أن يؤثر عليك.

منصة عربية (RTL) للتوعية الرقمية: فهم الخوارزميات، اكتشاف التضليل، حماية الخصوصية، واستعادة السيطرة على التجربة الرقمية. محتوى موثّق وتجارب تفاعلية، من غير نظريات مؤامرة ومن غير توجيه سياسي.

## الميزات

- **الصفحة الرئيسية** — Hero متحرك (شبكة إدراك رقمية)، 5 وحدات وعي، أحدث المقالات، تحدي اليوم.
- **5 وحدات**: افهم الخوارزمية `/algorithms`، التأثير الرقمي `/influence` (سيناريوهات تفاعلية)، الحقيقة والتضليل `/verify`، بياناتك الرقمية `/privacy` (قائمة تحقق تفاعلية)، مركز الوعي `/awareness`.
- **مرآتك الرقمية** `/digital-mirror` — تقييم تعليمي من 12 سؤالًا: 5 محاور، نقاط قوة، وخطة تطوير 7 أيام. يعمل محليًا بالكامل.
- **مختبر الخوارزمية** `/algorithm-lab` — محاكاة فيد افتراضي: شاهد/أعجب/تخطَّ وشاهد التوصيات تتغير، مع تصوير حلقة التغذية الراجعة.
- **قبل ما تعمل Share** (داخل `/verify`) — قائمة تحقق + تحليل لغوي توعوي لعنوان أو ادعاء، بنتائج استشارية فقط.
- **تحديات الوعي** `/challenges` — تحدي يومي، XP ومستويات وسلسلة أيام (localStorage).
- **مكتبة الوعي** `/library` — 12 مقالًا عربيًا كاملًا مع بحث وفلترة، وصفحات مقالات قابلة للمشاركة.
- **لوحة أدمن تجريبية محلية** `/admin` — إدارة مقالات وتحديات ومسودات (localStorage فقط، كلمة المرور التجريبية `idrak-admin`).

## التقنية

Next.js 16 (App Router) + TypeScript + React 19 + Tailwind CSS 4 + Framer Motion + Lucide Icons. عربي RTL أولًا، Mobile-first، SEO (metadata + sitemap + robots + Open Graph).

## التشغيل محليًا

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm start
```

لا توجد متغيرات بيئة مطلوبة. لا أسرار ولا مفاتيح API في الواجهة الأمامية.

## النشر على Vercel

اربط المستودع في Vercel (Framework Preset: Next.js) — لا إعدادات إضافية مطلوبة. كل push على `main` ينشر تلقائيًا.
